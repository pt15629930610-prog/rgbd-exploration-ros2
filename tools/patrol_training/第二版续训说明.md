# 大棚巡检语言适配器第二版

Windows 实验目录为 `D:\Qwen3-VL-2B\patrol_training\curriculum-v2`。双击该目录下的 `Preview-Patrol-v2.cmd`，输入自己的指令即可查看动作、巡检范围和起始行，空行退出。预览使用本机端口 18187，无需打开 Ubuntu。原来的仿真启动器仍加载第一版。

## 训练目标

“从左边第一行开始，把棚里的每条作物行都查完”包含一个起点和一个覆盖范围。第二版允许模型标注“指定起始行”和巡检“范围=全部”。起始行即使出现在句尾也修饰整次任务。单独说“只查左边第一行”只对应一次单行巡检。“查遍左边的行”把左侧作为整个巡检的筛选条件。序号、速度、圈数和米数保留在各自的原文片段里。

## 训练材料

| 文件 | 用途 |
|---|---|
| `data/train.jsonl` | 640 条本轮样本（含一条运行日志原话）和 160 条旧样本。可搜索“历史原话”查看错例和标准答案。 |
| `data/validation.jsonl` | 68 条验证样本，用于选训练轮次。 |
| `data/test.jsonl`、`data/paraphrase.jsonl` | 17 对易混说法和 3 组各 3 种长指令改写，用于首次盲测。 |
| `data/transfer.jsonl.locked` | 增加输出校验后使用的另一组 20 条独立题。文件内容为 JSONL。 |
| `data/incident.jsonl` | 单独回放训练集中那条真实失败指令，独立统计。 |
| `adapter/best.pt`、`adapter/patrol-lora.gguf` | 继续训练用的权重和 Windows 推理用的适配器。 |
| `adapter/history.json`、`runs/*/parent.sha256` | 验证损失和父检查点指纹。 |
| `evaluation/*.jsonl`、`evaluation/*summary.json`、`evaluation/previous.json`、`evaluation/continued.json` | 每题原话、预期和实际答案，以及分组得分。 |
| `source` | 本次运行所用的训练、评测脚本和语言解析代码。 |

在原来的 RTX 4060 和 unet 环境中载入第一版的 A、B 两个低秩矩阵，新建优化器，以学习率 0.00025 继续更新最后一个语言层的 262,144 个参数。视觉编码器和基础模型冻结。共训练 4 轮，按 68 道验证题的答案 token 平均负对数似然选中第 3 轮，从 0.1721 降到 0.0506。新旧适配器实际对照均采用同一 Q4 权重、0.75 强度和确定性解码。

## 怎么读成绩

新题首答要求动作顺序、引用、目标、方位、作物和范围都正确。评分忽略标点和空格，语义等价但切分不同也可能扣分。旧 48 题沿用编译后整份计划匹配的口径。条件、道路通行、图像识别和 Gazebo 完成率需要各自的验证。机器人当前的执行接口还缺少全棚遍历能力。

终端预览另提供六个固定示例。程序检查是否漏句、擅自添加左右、把巡检吞进调速等问题，必要时把错误发回模型重试一次。第二次仍未通过会指出原因。检查通过也可能误解语义。新鲜测试的原始首答与带示例校验的回答分别记在 `transfer-*.jsonl`。

最终预览在重试时可给句首速度加分隔符。每一个标为巡检的片段都会再由同一模型结合整句判断“各条符合条件的行 / 选中的一行 / 信息不足”。这一步解决了真实原话中漏掉“全部”的问题。若动作本身分错，范围复核也可能无能为力。

| 实测项目 | 第一版 | 续训版 |
|---|---:|---:|
| 34 条易混指令，首答完整标注 | 9/34 | 17/34 |
| 17 对中两句均正确 | 3/17 | 6/17 |
| 9 条长指令口语改写，首答完整标注 | 2/9 | 4/9 |
| 旧测试，完整计划正确 | 36/48 | 36/48 |
| 第二组 20 条新题，首答完整标注 | 3/20 | 4/20 |
| 同 20 条，固定示例和一次重试 | 6/20 | 8/20 |

最后另出 12 道新题，续训模型直接回答为 2/12，最终预览流程为 8/12。这些是开发者构造的小型行为测试，样本规模和措辞来源不足以估计现场总体成功率。真实失败原话在训练中出现过，模型直接回答仍漏步骤，最终预览得到调速、巡检全部行、指定起始行三个正确标注。详情见 `evaluation/final.jsonl`。可运行 `transfer_exam.py --root $root --experiment $next --preview` 复测。

已观察到两种典型错误。模型可能把“右侧这一排菜进去转转”和“右侧每一排菜都进去转转”解析错，也可能把上一动作的“左转”错误延续到下一条作物行。预览结果可以人工核对，尚未作为车上实际调度策略部署。

## 如何自己复训

下面以 PowerShell 为例。把新一轮保存在新的实验目录，以便随时回到这次权重。可先在仓库 `tools/patrol_training/patrol_curriculum.py` 中补充实际任务、标准答案及独立测试说法。训练样本应包含未限定方位的说法、同义改述、条件、禁止和只改一个词就改变含义的指令。测试中暴露的错例一旦用于下一轮训练，就要另外留新题验收。

```powershell
$root = 'D:\Qwen3-VL-2B\patrol_training'
$repo = 'C:\Users\pc\.codex\worktrees\66ef\robot_ws'
$scripts = Join-Path $repo 'tools\patrol_training'
$next = Join-Path $root 'curriculum-next'
$py = 'E:\ANACONDA\envs\unet\python.exe'
& $py -B "$scripts\patrol_curriculum.py" --root $root --experiment $next
& $py -B -u "$scripts\train.py" --root $root --experiment $next --resume "$root\curriculum-v2\adapter\best.pt" --epochs 4 --lr 0.00025 --group 8
& $py -B "$scripts\check_curriculum.py" --root $root --experiment $next --variant continued
& $py -B "$scripts\check_curriculum.py" --root $root --experiment $next --interactive
```

上述续训命令以第二版为父权重。若要复现第二版本身，将 `--resume` 改为 `"$root\adapter\best.pt"`（第一版）。评测参数 `--variant previous` 指第一版。运行 `transfer_exam.py --root $root --experiment $next` 可复现第一版和候选版在新鲜测试上的首答与校验对照。
